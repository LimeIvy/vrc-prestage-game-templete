# Development specification index

This folder contains the detailed specification for the Godot prototype of 「カケラのせかい（仮）」.

Status markers:
- `[LOCKED]`: required behavior.
- `[PROVISIONAL]`: current tuning value; keep configurable.
- `[UNRESOLVED]`: not decided; do not silently lock.
- `[DO NOT ADD]`: explicitly outside current design.

The root `AGENTS.md` is intentionally short. Codex should read only the documents relevant to the current task.
