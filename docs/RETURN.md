# きかん / Prestige and Economy

## Unlock and requirement
[LOCKED] First きかん available at STAGE100.
`RequiredReturnStage = min((ReturnCount + 1) * 100, 5000)`.
This is a minimum, not an exact required return stage. Actual previous return stage does not change the next requirement.

On きかん:
- current stage → 1
- keep characters, levels, なじみ, equipment, shards, materials, currency, milestone flags and settings
- repeatable material reward uses highest stage reached in the run

## Currency roles
[LOCKED]
- おやつ → character leveling
- パーツ → equipment leveling/gates
- boss shard material → shard leveling
- ひかり石 → gacha only

## ひかり石 progression
[LOCKED intent] Do not scale repeatable gacha currency with return stage.
First-time each 100-stage return requirement: 50 stones, through 5000 = 2,500 stones.
First-time every 500-stage milestone: extra 500 stones, ten milestones = 5,000.
Total fixed progression through 5000 = 7,500 stones = 150 pulls.
Daily = 500 stones.

## 500-stage milestones
First-time milestones: 500,1000,...,5000.
If multiple unclaimed milestones were crossed, claim all on return. Never missable.

[PROVISIONAL] Permanent bonus: +5% final damage per milestone, additive within one milestone category; ten = +50%, ×1.50.
[PROVISIONAL] Extra milestone materials: +2× regular reward for both snacks and parts, in addition to regular reward (~3× total).
[PROVISIONAL] Possible shard reward: STAGE500 SR+ shard ×1; STAGE1000+ SSR shard ×1. Random roll, not guaranteed god roll.

See BALANCE.md for repeatable material table.
