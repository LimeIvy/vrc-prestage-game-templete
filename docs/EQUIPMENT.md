# Equipment / もちもの

[LOCKED] One character equips exactly one もちもの. One もちもの has exactly three shard sockets. Max Lv30.
Stats are percentage/rate based. No flat attack and no HP.
Equipment uses パーツ only; never ひかり石.

## Enhancement
Normal levels deterministic. Probability gates at Lv5/10/15/20/25/30 only.

[PROVISIONAL] Gate success:
40%, 25%, 15%, 10%, 5%, 2%.

Failure:
- consumes パーツ
- level unchanged
- item not destroyed
- success chance does not accumulate
No pity, rescue, downgrade or destruction.

Normal band cost per upgrade:
Lv1→4 50; Lv5→9 150; Lv10→14 400; Lv15→19 1,000; Lv20→24 2,500; Lv25→29 6,000.

Gate attempt cost:
→5:100; →10:300; →15:800; →20:2,000; →25:5,000; →30:12,000.
Expected rough total ≈800K parts per Lv30 equipment, ≈3.2M for four.

## UI
Categories exactly `そうび / カケラ / その他`.

Character↔equipment assignment accessible both directions. Avoid required drag-and-drop.
