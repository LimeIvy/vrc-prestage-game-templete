# カケラのせかい 初期キャラクター・武器・カケラ正式ステータス

## 1. 文書の位置づけ

本書は、初期実装で使用するキャラクター、武器、カケラの数値仕様を定義する。

敵側の要求DPS曲線と、4人SSR最大育成時の理論チームDPS約527.8Mを固定基準とする。画像モック内の数値より本書を優先する。

### 固定事項

- 編成は4人
- キャラクターと武器の最大レベルは30
- 武器はキャラクター1人につき1個
- 武器1個につきカケラ用ソケットは3個
- カケラの最大レベルは5
- カケラはメイン効果1個とサブ効果1個
- メイン効果とサブ効果に同じ能力は付かない
- カケラ強化時はメインとサブが両方確定成長する
- キャラクターにアクティブスキルはない
- 基本属性付着率は20％
- 無属性キャラクターは属性付着を行わない
- UIは計算済みステータスを表示するだけとし、UI内で再計算しない

## 2. 敵側の基準

### 2.1 要求DPS

```text
STAGE 1       10
STAGE 1,000   1,000,000
STAGE 2,000   50,000,000
STAGE 3,000   250,000,000
STAGE 4,000   500,000,000
STAGE 5,000   1,000,000,000
```

### 2.2 区間式

```text
STAGE 1～1,000
RequiredDPS(s) = 10 × 1.011591^(s－1)

STAGE 1,000～2,000
RequiredDPS(s) = 1,000,000 × 1.0039197^(s－1,000)

STAGE 2,000～3,000
RequiredDPS(s) = 50,000,000 × 1.0016107^(s－2,000)

STAGE 3,000以降
RequiredDPS(s) = 250,000,000 × 2^((s－3,000)÷1,000)
```

### 2.3 敵HP

```text
通常敵HP = RequiredDPS(stage) × 5
ボスHP   = RequiredDPS(stage) × 15
```

適正DPSなら通常敵を5秒、ボスを15秒で倒せる。

## 3. 共通ステータス計算

### 3.1 キャラクターのレベル成長

キャラクターの基礎攻撃力は指数成長する。

```text
BaseAttack(level)
= round(
    AttackLv1
    × (AttackLv30 ÷ AttackLv1)^((level－1)÷29)
  )
```

初期データでは全キャラクターのLv.30攻撃力がLv.1の1万倍になるため、1レベルごとの倍率は約1.374倍となる。

### 3.2 武器のレベル成長

武器の攻撃力補正も指数成長する。

```text
WeaponAttackPercent(level)
= WeaponAttackLv1
  × (WeaponAttackLv30 ÷ WeaponAttackLv1)^((level－1)÷29)
```

### 3.3 最終攻撃力

```text
FinalAttack
= BaseAttack
  × (1 + WeaponAttackPercent + TotalShardAttackPercent)
```

攻撃力％はすべて加算してから基礎攻撃力へ掛ける。

### 3.4 最終攻撃速度

```text
FinalAttackSpeed
= BaseAttackSpeed
  × (1 + WeaponSpeedPercent + TotalShardSpeedPercent + PassiveSpeedPercent)
```

### 3.5 会心期待値

本書の会心ダメージは、通常攻撃へ追加される倍率を表す。会心ダメージ＋50％なら、会心時の合計ダメージは150％となる。

```text
ExpectedCriticalMultiplier
= 1 + FinalCriticalRate × FinalCriticalDamageBonus
```

### 3.6 1人分の期待DPS

```text
CharacterDPS
= FinalAttack
  × FinalAttackSpeed
  × (1 + FinalCriticalRate × FinalCriticalDamageBonus)
  × (1 + FinalElementDamagePercent)
  × PassiveReactionMultiplier
  × (1 + MilestoneDamagePercent)
```

### 3.7 加算上限

| 能力 | 下限 | 上限 |
|---|---:|---:|
| 攻撃速度 | 0.10回／秒 | 5.00回／秒 |
| 会心率 | 0％ | 100％ |
| 属性付着率 | 0％ | 100％ |
| 会心ダメージ追加量 | 0％ | 上限なし |
| 属性ダメージ | 0％ | 上限なし |

### 5.4 パッシブ処理上の規則

- 最終ダメージ倍率は攻撃力％へ加算しない
- 同一パッシブの効果を一回の攻撃へ複数回適用しない
- 敵撃破で解除される効果はボス再挑戦時にも解除する
- 反応ダメージ専用補正を通常攻撃へ適用しない
- 付着率補正を属性ダメージへ流用しない
- はこにゃの1.15倍は武器由来の値だけを対象とする

## 6. 初期武器

### 6.1 共通規則

- 全武器に3ソケットを付与する
- ソケット番号による性能差はない
- 同レアリティの武器は攻撃力補正を共通化する
- 武器ごとの差は固有補正で付ける
- 固有補正はLv.1から固定で、武器レベルでは成長しない
- 武器の付け替えに費用は発生しない
- 同じ武器個体を複数キャラクターへ同時装備できない

## 7. カケラ

### 7.1 生成規則

カケラ生成時に次を確定する。

```text
instance_id
rarity
main_stat
sub_stat
level = 1
is_locked = false
is_favorite = false
equipped_weapon_instance_id = null
socket_index = null
```

メイン効果とサブ効果は同じ能力にならない。再抽選や強化失敗はない。

### 7.2 抽選対象

| 能力ID | 表示名 | 計算方法 |
|---|---|---|
| `attack_percent` | 攻撃力 | 攻撃力％へ加算 |
| `attack_speed_percent` | 攻撃速度 | 攻撃速度％へ加算 |
| `critical_rate` | 会心率 | 会心率へ加算 |
| `critical_damage` | 会心ダメージ | 会心ダメージ追加量へ加算 |
| `element_damage_percent` | 属性ダメージ | 属性ダメージ％へ加算 |

HP、防御力、固定攻撃力、属性付着率は初期カケラの抽選対象へ含めない。

### 7.6 強化規則

- 初期状態はLv.1
- ボス討伐時に得る強化機会で1レベル上昇
- 最大Lv.5
- 強化成功率は100％
- レベル上昇時にメイン効果とサブ効果が同時に次段階へ成長
- 成長先は固定で、再抽選しない
- Lv.5のカケラへ強化機会を使用できない
- 装着中でも強化可能

### 7.7 ソケット規則

- 武器1個につき3ソケット固定
- ソケット番号は0、1、2を保存する
- ソケット自体はステータスを持たない
- 同じカケラ個体を複数ソケットへ装着できない
- 別武器に装着中のカケラを選んだ場合は、元の武器から外して移動する
- カケラの付け替えに費用は発生しない
- 空ソケットは空文字またはnullで表す

## 8. 4人SSR理論値の固定fixture

### 8.1 入力値

このfixtureは敵曲線との接続を検証するための正規化された上限テストであり、初期実装では4人とも同じ値を使用する。

```text
SSR Lv.30基礎攻撃力  100,000
武器攻撃力補正       ＋1,200％
カケラ攻撃力補正     ＋1,500％
最終会心率           88％
会心ダメージ追加量   ＋290％
攻撃速度補正         ＋150％
属性ダメージ         ＋190％
パッシブ倍率         ×1.22
マイルストーン       ＋50％
```

カケラ攻撃力＋1,500％は、SSR Lv.5の攻撃力メインを3個装着した値とする。ほかの最終値は、キャラクター、武器、カケラ、凸、マイルストーンを合算したfixture入力である。個別装備画面の合計値とfixtureの合計値が一致することを自動テストする。

### 8.2 計算

```text
FinalAttack
= 100,000 × (1 + 12.00 + 15.00)
= 2,800,000

FinalAttackSpeed
= 1.00 × (1 + 1.50)
= 2.50回／秒

ExpectedCriticalMultiplier
= 1 + 0.88 × 2.90
= 3.552

1人DPS
= 2,800,000 × 2.50 × 3.552 × 2.90 × 1.22 × 1.50
= 131,953,248

4人DPS
= 131,953,248 × 4
= 527,812,992
```

### 8.3 到達ステージ

```text
250,000,000 × 2^((stage－3,000)÷1,000)
= 527,812,992

stage ≒ 4,078
```

STAGE 4,078付近の敵HP目安は次のとおり。

```text
要求DPS   約527.8M
通常敵HP  約2.64B
ボスHP    約7.92B
```

## 9. 初期編成の検証

### 9.1 最小開始値

初期4人をN基準、装備なし、反応なしとして確認する。

```text
3攻撃力 × 毎秒1回 × 4人 = 約12DPS
```

STAGE 1の要求DPS10を少し上回り、通常敵を約4.2秒で倒せる。

### 9.2 推奨テスト編成

```text
ぽて      火・万能
ねむりん  水・付着後火力
くろも    草・属性付着
のびる    無・属性反応なし
```

火、水、草、無属性、会心、付着、反応、無属性火力を一度に検証できる。

### キャラクター

- 全キャラクターがLv.1とLv.30で表の攻撃力になる

## 11. データ実装時の識別子

表示名を保存データへ直接使用しない。定義IDと個体IDを分離する。

```text
CharacterDefinition.id       char_pote
OwnedCharacter.definition_id char_pote

WeaponDefinition.id          equip_stardrop_spear
OwnedWeapon.instance_id      weapon_uuid
OwnedWeapon.definition_id    equip_stardrop_spear

ShardDefinition.id           shard_generated_ssr
OwnedShard.instance_id       shard_uuid
OwnedShard.main_stat         attack_percent
OwnedShard.sub_stat          critical_rate
```

同種の武器とカケラを複数所持できるようにする。装備関係は表示名ではなく個体IDで保存する。
