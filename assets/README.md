# Visual Assets

画像素材の配置先です。詳細な命名・サイズ・制作方針は `docs/ASSET_REQUIREMENTS_REVISED.md` を参照してください。

実装側は、該当ファイルが存在する場合に画像を表示し、存在しない場合は仮表示へフォールバックします。

主要フォルダ:

```text
backgrounds/common/
characters/main/
enemies/main/
equipment/weapons/
equipment/charms/
equipment/journey_goods/
shards/main/
items/currencies/
items/materials/
items/memories/
icons/navigation/
icons/elements/
icons/stats/
icons/actions/
icons/status/
effects/common/
placeholders/
```
